# Олимпиадная математика 10 класса

Учебный проект Партанского Ильи Михайловича на 2026/2027 год: официальный архив задач, исследование методов и годовая программа из 34 тем по 90 минут. Основа - региональный этап ВсОШ; муниципальный этап и МОШ дополняют подготовку.

Регулярные занятия фактически начинаются 3 октября. [Гайд преподавателю](course/START_HERE.md), [рабочая последовательность с октября](course/operational-plan.md), [сегодняшний сценарий с решениями](course/sessions/2026-10-03/teacher.md), [листок задач для печати](course/sessions/2026-10-03/student.pdf). С учетом каникул и примерно пяти матбоёв ожидается около 23 пар; программа из 34 тем не является журналом проведённых занятий.

[Оригинальные комплекты](archive/) и готовые планы находятся в репозитории через Git LFS. [Локальный каталог](index.html) можно открыть после клонирования или распаковки готового ZIP без запуска сервера. [Сайт](https://partanskiy.github.io/teaching/courses/olympiad-math-10/) остается дополнительным способом просмотра опубликованного комплекта.

## Два согласованных плана

- План для сдачи повторяет структуру исходного документа: титульный лист, пояснительная записка, цели, место кружка в учебном плане, сводная тематическая таблица и планируемые результаты. Календарно-тематического плана, ссылок на проект и номеров из внутреннего каталога в нем нет. [Текст программы](course/submission.md), [Word](course/План_для_сдачи_2026-2027.docx), [PDF](course/План_для_сдачи_2026-2027.pdf).
- Годовая рабочая программа содержит конкретные задачи, домашнюю работу и контрольный резерв для всех 34 тем. [Программа](course/plan.md), [Word](course/План_34_занятия_2026-2027.docx), [PDF](course/План_34_занятия_2026-2027.pdf), [пояснения преподавателю](course/teacher.md). Для дат и фактического порядка использовать [рабочую последовательность с октября](course/operational-plan.md).

Оба документа строятся из data/lessons.json и data/program.json. Общими являются автор, учебный год, разделы и объём 68 академических часов. Часы каждого раздела программы для сдачи рассчитываются по занятиям рабочего плана. Подробные темы, последовательность занятий, учебные цели и задачи находятся в рабочем плане. Проверка scripts/check_plans.py выявляет расхождения. Изменения вносятся в исходные данные и скрипт make_course.py; пересобираются затронутые документы.

## Получение готовых материалов

Установить Git LFS через системный менеджер пакетов, один раз выполнить git lfs install, затем клонировать teaching. Обычный git clone скачивает оригинальные PDF и оба плана текущей версии автоматически. Если клон уже был создан без LFS, выполнить git lfs pull из корня репозитория.

[Полный комплект для работы без интернета](https://github.com/partanskiy/teaching/releases/download/olympiad-math-10-2026.10.01/olympiad-math-offline.zip) остается альтернативой без Git: распаковать ZIP и открыть index.html. Для подготовки извлеченного текста к локальным проверкам после клонирования:

```sh
python scripts/restore_materials.py
```

restore_materials.py сверяет уже скачанные оригиналы и извлекает текст без сетевых загрузок. Явный --release восстанавливает зафиксированный комплект из Releases. PDF, DOCX и растровые изображения версионируются через GitHub LFS; кэши и ZIP исключены из Git. История состоит из небольших английских Conventional Commits. [Правила хранения и обновления](BINARY_FLOW.md).

## Где искать

- Архив оригиналов разделён по олимпиаде, этапу, учебному году и региону публикации; он доступен в полном комплекте или [отдельном ZIP](https://github.com/partanskiy/teaching/releases/download/olympiad-math-10-2026.10.01/olympiad-math-materials.zip).
- [Исследование задач](research/analysis.md) объясняет тематическую разметку и выбор программы.
- [Состав и происхождение коллекции](research/collection.md) содержит покрытие по годам и регионам.
- [Календарь 2026/2027](research/calendar.md) отделяет опубликованное от планировочных предположений.
- [Реестр файлов CSV](data/documents.csv), [реестр задач CSV](data/tasks.csv), [связь задач с занятиями CSV](course/task-map.csv).
- [Недоступные ссылки](data/download-failures.json) и [ограничения распознавания](research/quality.md).

Тема и прием решения - разные метки. Для муниципального банка вне проверенной выборки метки автоматические и предварительные; они не использовались как основание статистики курса. Формулы и рисунки проверяются по PDF, текстовый индекс предназначен для поиска. Контрольный резерв скрыт в каталоге по умолчанию.

## Обновление

Нужны уже установленные Python, lxml, Poppler и 7z; установки через pip нет. Сохраненные ссылки повторно не скачиваются. Полный цикл описан в [scripts/README.md](scripts/README.md). Автоматическое расписание обновлений не настроено. Дата исследования: 01.10.2026.
