## Оформление и сборка

Правила печати находятся в AGENTS.md: Typst, два одинаковых A5 на горизонтальном A4, внутри одна колонка, заголовки по центру, дата справа, отдельная строка "Задача N (источник)" с курсивным источником, между задачами отступ, по центру пунктир разреза. Обычно десять задач, без имени преподавателя на ученическом листке. Длинные формулы переносить явно с повтором знака. Учительские решения должны быть полными; геометрия - с точными чертежами. В Typst для знака делимости использовать divides, а не mid, которое может напечататься как имя функции.

Программа для сдачи повторяет образец Червякова: сводная тематическая таблица, без КТП, внутренних ID и ссылок на репозиторий. Рабочий план содержит подробности. Частный DOCX Червякова лежит вне Git и для штатной сборки не требуется; формат реализован в скриптах.

Команды выполнять из папки курса. Системные зависимости: Python, lxml, Typst 0.15.1, Poppler; для индивидуальной книги также Ghostscript. Pandoc нужен для рабочего DOCX. LibreOffice 7 ноября не установлен; рабочий PDF собирается через Typst с --working-only. Точный повторный экспорт официального PDF требует LibreOffice; готовые файлы для сдачи сохранены. Не использовать pip/pipx.

```sh
python scripts/check_plans.py
node scripts/check_catalog.js
python scripts/build_operational_plan.py
python scripts/export_documents.py --working-only
python scripts/build_session_handout.py 2026-10-24
python scripts/build_session_handout.py 2026-10-17 --variant advanced
typst compile --root . course/sessions/2026-10-17/advanced-solutions.typ course/sessions/2026-10-17/advanced-solutions.pdf
python course/sessions/2026-10-24/build_figures.py
typst compile --root . course/sessions/2026-10-24/solutions.typ course/sessions/2026-10-24/solutions.pdf
python scripts/build_individual_pack.py
```

Это независимые команды по назначению, выполнять нужные. Сборщик листка проверяет связь с модулями; supplemental advanced разрешает дополнительные региональные и МОШ-задачи нужного класса, но не резерв. На 31 октября нового student.typ нет по решению пользователя.

После клонирования с LFS скрипт restore_materials.py сверяет оригиналы и создаёт извлечённый текст без сети; он также может переписать метаданные извлечения в documents.json, поэтому смотреть diff. Полная инструкция: [scripts/README.md](scripts/README.md).
