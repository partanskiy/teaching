# Воспроизведение и обновление

Команды выполняются из корня репозитория olympiad-math. Скрипты используют только стандартную библиотеку Python и уже установленный lxml. Для файлов нужны Poppler и 7z; для документов - Pandoc и LibreOffice. Установка через pip не используется.

## Локальная сборка

После Git-клона восстановить оригиналы: python scripts/restore_materials.py. Для пересборки планов исходные страницы публикаций не нужны. Команды выполнять из корня проекта по порядку:

```sh
python scripts/annotate.py
python scripts/build_catalog.py
python scripts/make_course.py
python scripts/publish.py
```

Скрипт build_archive создаёт реестр и извлекает текст, не изменяя оригиналы. build_catalog выделяет номера 10 класса и связывает публикации. annotate собирает исследовательские файлы annotations-*.txt, сортируя их по имени; поздний файл с тем же идентификатором уточняет разметку. make_course содержит исходный план 34 занятий. publish создаёт отчёты, CSV и данные локального каталога.

Ручные исследовательские записи хранятся в research/annotations-*.txt и не генерируются по ключевым словам. Ключи решения записаны после сверки с опубликованным решением. Остальные метки приемов у прочитанных условий являются педагогическими кандидатами.

После сборки экспортировать оба согласованных документа и проверить результат:

```sh
python scripts/export_documents.py
python scripts/check_plans.py
python scripts/validate.py
node scripts/check_catalog.js
```

План для сдачи собирается непосредственно из data/lessons.json и data/program.json. Его оформление реализовано в scripts/docx_layout.py и повторяет структуру исходного образца. Для рабочего Word используется стиль уже собранного документа для сдачи; отдельный бинарный шаблон не нужен. PDF создаётся LibreOffice.

Проверка без готовых документов: python scripts/check_plans.py --source-only. Для проверки собранного официального DOCX без рабочего Word и PDF: python scripts/check_plans.py --submission-only. Это используется в GitHub Actions.

## Загрузка новых источников

data/candidates.json содержит отобранные публикации и их предметные метаданные. data/pages.json содержит статус и происхождение фактических загрузок. collect.py не скачивает повторно адрес со статусом ok; --force нужен только при сознательной повторной проверке.

```sh
python scripts/collect.py --url-file data/expanded-urls.txt --workers 6
```

discover.py извлекает ссылки из уже сохранённых официальных индексов и архивных страниц. Его выполнение заново формирует список кандидатов, поэтому прежде сохранить ручные добавления, если они появились. Новый сезон, класс и роль файла нужно проверить по самой публикации до включения в учебный банк. После загрузки исходных публикаций python scripts/build_archive.py заново создаёт оригиналы и реестр. В обычном Git-клоне архив восстанавливается из Release, а этот этап не выполняется до загрузки источников.

У коллектора есть ограничение размера файла 35 MiB и тайм-аут. Не загруженные кандидаты не объявляются документами. Для tasks.olimpiada.ru используется публичный HTTP-адрес того же файла; остальные HTTPS-проверки не отключаются. При недоступности сети конкретного окружения загрузку следует запускать в разрешённом сетевом режиме, без отключения проверки сертификатов.

## Что проверять после обновления

validate.py проверяет сигнатуры и SHA256 всех документов, ссылки карточек, границы страниц, полный состав регионального ядра и МОШ, 34 занятия, часы, наличие сверенных решений у основных тематических задач и отсутствие преждевременной выдачи контрольного резерва. Недоступные исторические ссылки и проблемы муниципального текстового слоя остаются в отдельных журналах.

Календарная справка research/calendar.md и data/calendar.json обновляются после чтения новых первичных источников. Скрипты не угадывают сроки следующего сезона. Оформление хранится в исходном коде; оба Word-документа и PDF являются результатами сборки.
