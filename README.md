# Teaching

Учебные материалы Партанского Ильи Михайловича: банки задач, программы занятий, планы для сдачи и рабочие планы с методическими пояснениями.

Каждый курс находится в отдельной папке courses/. У него свои исходные данные, исследование задач, документы и версия готового комплекта.

| Курс | Материалы |
| --- | --- |
| Олимпиадная математика, 10 класс, 2026/2027 | [Описание и банк задач](courses/olympiad-math-10/README.md), [официальные комплекты](courses/olympiad-math-10/archive/), [план для сдачи Word](courses/olympiad-math-10/course/План_для_сдачи_2026-2027.docx), [рабочий план PDF](courses/olympiad-math-10/course/План_34_занятия_2026-2027.pdf) |

В нынешнем курсе 422 официальных документа ВсОШ и МОШ, 1045 карточек задач и 34 занятия по 90 минут. Основа подготовки - региональный этап ВсОШ. Оба плана используют общие темы, порядок, цели и часы; проверки выявляют расхождения.

PDF, DOCX и растровые изображения находятся в дереве репозитория через GitHub LFS. Тексты, реестры, скрипты и редактируемые SVG используют обычный Git. Установить Git LFS через системный менеджер пакетов, затем:

```sh
git lfs install
git clone https://github.com/partanskiy/teaching.git
cd teaching
```

Клонирование автоматически скачивает оригиналы текущей версии. Если клон уже создан без LFS, выполнить git lfs pull. Локальный каталог courses/olympiad-math-10/index.html открывается без сервера. Для подготовки текстового индекса к проверкам:

```sh
cd courses/olympiad-math-10
python scripts/restore_materials.py
```

[Готовые ZIP в Releases](https://github.com/partanskiy/teaching/releases) позволяют получить опубликованный комплект без Git LFS. [Существующий сайт](https://partanskiy.github.io/teaching/) остается дополнительным способом просмотра опубликованной версии; для работы с репозиторием он не нужен.

Хранение, лимиты и будущий перенос в Yandex Object Storage описаны в [BINARY_FLOW.md](BINARY_FLOW.md). Правила участия приведены в [CONTRIBUTING.md](CONTRIBUTING.md). Происхождение и права на оригинальные задачи указаны в [уведомлении курса](courses/olympiad-math-10/NOTICE.md) и реестре каждого документа.
