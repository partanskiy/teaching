# Teaching

Учебные материалы Партанского Ильи Михайловича: банки задач, программы занятий, планы для сдачи и рабочие планы с методическими пояснениями.

Каждый курс находится в отдельной папке courses/. У него свои исходные данные, исследование задач, документы и версия готового комплекта. Изменения одного курса не требуют пересборки остальных.

| Курс | Материалы |
| --- | --- |
| Олимпиадная математика, 10 класс, 2026/2027 | [Описание и банк задач](courses/olympiad-math-10/README.md), [план для сдачи](courses/olympiad-math-10/course/submission.md), [рабочий план](courses/olympiad-math-10/course/plan.md) |

В нынешнем курсе 422 официальных документа ВсОШ и МОШ, 1045 карточек задач и 34 занятия по 90 минут. Основа подготовки - региональный этап ВсОШ. Оба плана используют общие темы, порядок, цели и часы; проверки выявляют расхождения.

Тексты, реестры, небольшие иллюстрации и инструменты находятся в Git. Крупные оригиналы и готовые DOCX/PDF публикуются в [Releases](https://github.com/partanskiy/teaching/releases). Способ хранения, просмотра и обновления описан в [BINARY_FLOW.md](BINARY_FLOW.md).

Для работы с текущим курсом после клонирования:

```sh
cd courses/olympiad-math-10
python scripts/restore_materials.py
```

Правила участия приведены в [CONTRIBUTING.md](CONTRIBUTING.md). Происхождение и права на оригинальные задачи указаны в [уведомлении курса](courses/olympiad-math-10/NOTICE.md) и реестре каждого документа.
